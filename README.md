## 📌 About This Repository

This repository contains my hands-on exercises from Kaggle's Intro to SQL course. It documents my practice with SQL queries, data filtering, sorting, aggregation, and joining tables.

The objective is to strengthen my SQL fundamentals and demonstrate practical learning as I continue developing my skills in Data Science and Data Analytics.

## 🧠 Concepts Covered

| SQL Concept | What I Practiced |
|---|---|
| SQL & BigQuery | Introduction to querying data |
| SELECT, FROM & WHERE | Selecting columns and filtering records |
| ORDER BY | Sorting query results |
| GROUP BY | Grouping records for analysis |
| HAVING | Filtering grouped results |
| COUNT() | Counting records |
| AS | Creating aliases for columns and tables |
| WITH | Writing Common Table Expressions (CTEs) |
| JOIN | Combining related data from multiple tables |
